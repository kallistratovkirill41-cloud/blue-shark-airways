Blue Shark Airways — статический сайт
=====================================

Как запустить на Cloudflare Pages:

1. Зайди на https://dash.cloudflare.com
2. Pages → Create a project → Upload assets
3. Загрузи всю папку blue-shark-airways
4. Нажми Deploy

Или через Git (если есть репозиторий).

Структура:
- index.html     — главная страница
- css/style.css  — все стили
- cargo/         — подсайт Blue Shark Cargo (адрес /cargo/)
- images/        — логотипы и картинки
